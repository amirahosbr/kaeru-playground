What is Kaeru?

Kaeru is an AI tool that helps you edit websites in plain language. No coding experience needed. Instead of writing code directly, you describe what you want and Kaeru makes the changes for you.

How to use this site

  1. Open in Kaeru: Open this folder in the Kaeru desktop app
  2. Preview: Click "Preview" to see the website in your browser
  3. Ask for changes: In Kaeru, describe what you want to change in everyday language
  4. See the result: Refresh the preview to see your changes

What you can change

This site has three files: index.html (the page structure), about.html (this page), and styles.css (colors, fonts, layout). You can ask Kaeru to:

  • Change text content ("Change 'Welcome' to 'Hello'")
  • Modify colors ("Make the button green")
  • Adjust spacing and layout ("Add more space between items")
  • Style interactive elements ("Make buttons change color on hover")
  • Add visual effects ("Add a shadow to cards")
  • And much more!

CSS glossary

Selector
The part of CSS that targets which HTML element to style. Examples: .class-name, #id-name, button
Property
What you're changing. Examples: color, background, padding, font-size
Value
What you're changing it to. Examples: #0066cc (color), 1rem (size), flex (layout)
Color codes
Ways to specify colors: #0066cc (hex), rgb(0, 102, 204), or color names like blue
Units
px (pixels), rem (relative to base size), em (relative to parent), % (percentage)
Pseudo-class
Special state of an element. :hover means "when you hover over it", :focus means "when it's selected"
