# Kaeru Playground

A small practice website for people who are new to editing sites in **Kaeru**.

You do not need coding experience. Open this folder, look at the page, and ask Kaeru to change things in everyday language.

## What is in this folder?

- `index.html` — the home page
- `about.html` — a short about page
- `styles.css` — colors, fonts, and layout

That is the whole site. No install steps. No build tools.

## How to practice in Kaeru

1. Open this folder in the Kaeru desktop app.
2. Preview the home page.
3. Ask for a change, then check the preview again.

### Example asks

- “Make the button green”
- 「見出しを大きくして」
- “Change こんにちは to Good morning”
- “Add a new sentence under the headline”

Feel free to experiment. This site is only for practice.
